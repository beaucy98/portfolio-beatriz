Enfoque

Diseño y prototipado de interfaces con Figma y Adobe XD, seguido de la implementación frontend. El enfoque Mobile First permite priorizar el contenido y adaptar la composición a distintos tamaños de pantalla.

Trabajo realizado

Maquetación con HTML semántico; layouts mediante Flexbox y CSS Grid; adaptación con media queries y variables CSS; animaciones y transiciones; mantenimiento y evolución de interfaces existentes.

Tecnologías

Figma · Adobe XD · HTML5 · CSS3 · SCSS · Flexbox · CSS Grid · JavaScript
